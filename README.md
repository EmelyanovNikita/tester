## Научить работать с конфигой
В конфиге будут заданы адреса (gRPC) сервера, который поднимается тестером, и удаленного (gRPC) сервера.
Также в конфиге будет информация о нахождении `mm_server_api.proto`, `mm_objects.proto` файлах.
